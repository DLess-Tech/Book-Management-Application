# Book-Management-Application

**Overview**
The Book Management Application is a Java desktop program that uses a graphical user interface (GUI) to organize and manage book records.
It allows users to view book information, navigate between records, and add books to a list. Each record can contain a book's title, author's name, email, publication date, page count, and price.

****Require Data Files****
To run the application, you must provide the required CSV file and place it in the appropriate project directory. The file must use the exact filename expected by the program for the data to load correctly.
Note: Without the required CSV file, some application features may not work as intended. (random_books.csv and Books.csv)

****Features:****
Graphical User Interface: Built using Java Swing.
Book Records: Stores information about books and their authors.
Record Navigation: Move between book records using Previous and Next buttons.
Add Books: Add new records to the list.
CSV File Handling: Read and import book data from CSV files.
Input Validation: Handles invalid numeric values and publication dates.
Performance Timing: Measures the time taken for selected operations.
